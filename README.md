# 📊 Online Learning Behavior Analysis 

## 🎯 Project Overview
An exploratory data analysis (EDA) of global online learning patterns. This project investigates how factors like education level, field of study, and daily learning hours impact course completion rates.

## 💡 Key Insights
* **Education Impact:** Postgraduate students show the highest completion rates (~62.4%) compared to other groups.
* **Platform Preference:** Udacity is the most preferred platform, with the majority of learners using Desktop devices.
* **Low Correlation:** Analysis shows that the specific 'Field of Study' is a weak predictor of completion, suggesting engagement depends more on other behavioral factors.

## 🛠️ Tech Stack
* **Language:** Python 3.13
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Tools:** Jupyter Notebook, VS Code, Git/GitHub
